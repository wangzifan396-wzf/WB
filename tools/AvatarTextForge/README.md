# 文字头像

文字头像：取首字母并由名称哈希生成稳定色相，圆形/方角可切，带预览，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/AvatarTextForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
