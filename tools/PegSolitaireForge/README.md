# PegSolitaireForge

孔明棋（Peg Solitaire）：十字形棋盘上满布棋子，每次跳过相邻的棋子并吃掉它（落点须为空）。目标是把所有棋子吃到只剩 1 子，提供重置，纯前端离线经典单人谜题。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用
