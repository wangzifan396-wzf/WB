# UrlForge

离线 URL 工具箱：URL 解析、查询参数编码 / 解码 / 排序、Slug 生成、URL 规范化与构建。纯前端、零依赖、数据永不离机。

## 功能
- **URL 解析**：拆分协议、认证、主机、端口、路径、查询、哈希、origin。
- **查询参数**：对象 ↔ 查询串互转、参数按字典序排序。
- **Slug 生成**：大小写归一、Unicode 保留（中文不丢失）、可切换分隔符。
- **URL 构建 / 规范化**：重组 URL、小写协议主机、去除默认端口、排序参数。

## 用法
直接用浏览器打开 `index.html` 即可，无需安装、无需联网。

## 测试
```bash
node _test.js      # 纯函数断言
node smoke.js      # jsdom UI 冒烟（需 npm i jsdom）
```
