# 轨道与逃逸速度

基于开普勒第三定律由半长轴求轨道周期；计算地球静止轨道高度、地表圆轨道速度与逃逸速度，全程本地完成。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
