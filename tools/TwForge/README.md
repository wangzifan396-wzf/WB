# TwForge

CSS 声明与 Tailwind 原子类双向互译：覆盖布局、间距、字号、圆角、颜色与 flex 相关常用属性，间距按 4px 刻度换算，未覆盖的写成任意值语法。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/TwForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

