# EzaForge

目录树生成：把一组文件路径渲染成带分支线条的树状结构，模拟 eza / ls 的可视化输出，粘贴路径即可查看层级。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/EzaForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
