# 简历生成

简历生成器：将结构化 JSON（姓名/技能/经历/教育）转换为排版整齐的 Markdown 简历，离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ResumeForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
