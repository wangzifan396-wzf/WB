# 词向量

用确定性哈希生成词向量并算余弦相似度，演示语义接近度。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/EmbeddingForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node smoke.js   # jsdom 冒烟测试
```
