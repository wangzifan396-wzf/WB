# FlipForge

文字翻转工具：把文本转换成上下颠倒的“倒置体”（用 Unicode 镜像字符 + 反序），或仅反序、或左右镜像，社媒梗图、恶搞标题与趣味签名随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/FlipForge/

直接用浏览器打开 `index.html` 即可。
