# FancyTextForge

花式字体转换：把普通文字变成全角、圆圈字、小型大写或带删除线的样式，做标题、昵称与社媒文案时随手可用，纯 Unicode、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/FancyTextForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
