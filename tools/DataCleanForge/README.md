# 数据清洗

数据清洗：统一换行符/去控制字符/修整行首尾/压缩连续空格/去空行，可组合，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

## 本地运行

直接用浏览器打开 `index.html` 即可。
