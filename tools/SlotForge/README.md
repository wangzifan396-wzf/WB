# SlotForge

老虎机（Slot Machine）：三个转轮随机旋转出 🍒🍋🔔⭐💎7️⃣，三连按倍率赔付、两连赔 2，带演示余额与下注，做休闲娱乐与概率直觉随手可用，零依赖离线可玩。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
