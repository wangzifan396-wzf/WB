# TuringForge

图灵机模拟器。用一段简洁的 DSL 定义纸带、起始/接受/拒绝状态与转移规则，单步或连续推演，实时可视化磁带与读写头位置。

## 语法
```
tape: 1011          # 初始纸带（_ 为空白符）
start: q0           # 起始状态
accept: qa          # 接受状态
reject: qr          # 拒绝状态
q0,1 -> q0,1,R      # 状态,读 -> 新状态,写,方向(L/R/S)
```

## 特性
- 单步 / 连续推演，磁带自动双向扩展
- 读写头高亮，停机判定（接受 / 拒绝 / 停机 / 超时）
- 纯前端、零依赖、离线可用
