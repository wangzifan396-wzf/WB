# DeltaForge

Diff 美化：解析 unified diff，将新增、删除、文件头与区块头分别着色高亮，离线渲染更易读的变更预览。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/DeltaForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
