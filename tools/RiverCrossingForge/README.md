# RiverCrossingForge

渡河谜题（狼羊菜）：农夫要把狼、羊、菜运过河，船每次只能带一样，且不能把狼和羊、或羊和菜单独留在一岸。用广度优先搜索求出最少步骤解法，也可手动点击尝试，经典逻辑启蒙，离线零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用
