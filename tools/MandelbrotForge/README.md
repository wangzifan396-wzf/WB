# 曼德博

曼德博集合（Mandelbrot）：对复参数 c 迭代 z=z²+c 计算逃逸时间，离线精确。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
