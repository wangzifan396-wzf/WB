# BattleForge

海战棋（Battleship）：10×10 海域里藏着电脑的 5 艘战舰（长度 5/4/3/3/2）。逐格炮击，命中显示红、未中显示蓝，击沉全部即获胜。纯前端离线，单人推理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/BattleForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
