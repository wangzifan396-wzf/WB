# NonogramForge

数织（Nonogram / Picross）：根据每行每列旁的数字线索（连续填充块的长度），在网格里填出隐藏的像素图案。提供 5×5 / 10×10 随机谜题、检查与显示解法，逻辑推理与休闲解谜两不误，离线零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
