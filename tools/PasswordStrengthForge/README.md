# 密码强度

密码强度评估（zxcvbn-lite）：基于字符集大小估算熵，并对重复/连续/低多样性施加惩罚，输出强度等级 0-4，离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/PasswordStrengthForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
