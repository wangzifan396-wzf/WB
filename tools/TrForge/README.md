# TrForge

字符集变换：像 tr 一样把一组字符映射为另一组，支持删除(-d)、压缩重复(-s)与 a-z 区间展开。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/TrForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
