# NameGenForge

奇幻名字生成器：用一套音节表随机拼出富有中土 / 龙与地下城气息的角色名、地名与 NPC 名，可指定数量，跑团、写作与游戏设定随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/NameGenForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
