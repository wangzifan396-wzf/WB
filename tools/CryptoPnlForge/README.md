# CryptoPnlForge

录入多笔建仓（数量 / 成本单价）算均价成本，再按当前价格给出市值、盈亏与收益率。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CryptoPnlForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
