# 生存分析

Kaplan-Meier 生存曲线估计：由事件时间与删失标记逐步估计生存函数 S(t)，离线精确。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
