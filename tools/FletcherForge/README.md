# FletcherForge

计算 Fletcher-16 / Fletcher-32 校验和（轻量错误检测，比 CRC 更快），常用于网络与存储校验，离线计算。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/FletcherForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言

```
