# CompoundForge

复利增长与定期定额投资：输入本金、年化收益、年限与复利频率，含每月定投，算出未来价值、累计本金与利息收益。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CompoundForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
