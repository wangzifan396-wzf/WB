# JSON工具

JSON 工具：格式化（缩进）、压缩（去空白）、校验三合一，本地离线处理，不上传数据。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/JsonFormatForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
