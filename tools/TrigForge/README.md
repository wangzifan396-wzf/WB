# 三角函数计算器

正弦/余弦/正切与反三角函数计算，支持角度(°)与弧度(rad)互转，附 sin²θ+cos²θ=1 恒等式校验。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/TrigForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言

```
