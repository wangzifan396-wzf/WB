# Base62Forge

Base62 互转：在 0–9A–Za–z 共 62 个字符间编码整数（基于 BigInt 精确），常用于短链接、 YouTube ID 等紧凑标识，离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/Base62Forge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
