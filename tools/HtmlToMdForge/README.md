# HtmlToMdForge

把常见 HTML 转换为 Markdown：标题、加粗、斜体、链接、图片、列表、引用、代码块等，便于把网页片段整理进笔记，离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/HtmlToMdForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
