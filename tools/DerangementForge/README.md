# 错排数

错排数（子阶乘 !n）：n 个元素全错位的排列数，递推精确，离线计算。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

## 本地运行

直接用浏览器打开 `index.html` 即可。
