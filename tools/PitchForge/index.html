PitchForge · 音名频率参照

十二平均律（A4 = 440 Hz）下的音名↔频率换算、音分偏差、和弦组成音、移调与音阶，全部纯前端计算，并可用 Web Audio 实时试听。零依赖、数据不出浏览器。

支持 C D E F G A B 七音 + #/b 变音记号 + 八度数字（科学音高记法：C4 = 中央 C，A4 = 440 Hz）。
将任意频率映射到最近的半音，并给出与标准音的音分（cents）偏差。
点击每个音右侧的「听」单独试听；「▶ 琶音试听」按顺序播放全部组成音。
正数上移、负数下移；例如 C4 上移 2 半音 = D4，下移 1 = B3。
包含自然大调、三种小调、各种教会调式，以及五声 / 蓝调音阶。
