# PitchForge

单文件、零依赖、本地优先的**十二平均律音名频率参照计算器**。打开即用，所有计算都在浏览器本地完成，数据不出机。

## 功能

- **音名 → 频率**：输入 `A4` / `C#5` / `Eb3` 等科学音高记法，得到频率、MIDI 编号、周期与空气中波长。
- **频率 → 音名**：任意频率映射到最近的半音，并给出与标准音的**音分（cents）偏差**。
- **和弦**：选择根音与和弦类型（大/小/属七/大七/小七/挂留/增减/九和弦等），列出全部组成音与频率，支持逐音或琶音试听。
- **移调**：将一个音名上/下移任意半音数。
- **音阶**：自然大调、三种小调、七种教会调式、五声与蓝调音阶，组成音与频率一览，可顺序试听。
- **Web Audio 试听**：用浏览器原生 `AudioContext` 实时播放，无需任何音频文件或外部请求。
- **可换记谱**：升号 `#` / 降号 `b` 自由切换；A4 基准可在 415–466 Hz 间调整（如 432 Hz 派）。

## 原理

采用十二平均律（12-TET），基准 `A4 = 440 Hz`：

```
f(n) = 440 · 2^((midi − 69) / 12)
```

其中 `midi` 为 MIDI 音高编号（C−1 = 0，A4 = 69）。音名解析支持 `C D E F G A B` 七音加 `#`/`b` 变音记号与八度数字。
