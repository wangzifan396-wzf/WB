# GitLogForge

粘贴 git log 输出即得团队画像：作者排行、星期与时段分布、月度趋势、Conventional Commits 规范率与不合规标题清单，并给出夜间/周末占比等观察。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/GitLogForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
