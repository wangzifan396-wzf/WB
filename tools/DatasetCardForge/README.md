# 数据集卡片

按名称/类型/来源/规模/许可/局限生成标准化数据集卡片（含构成与偏见审计），离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/DatasetCardForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
