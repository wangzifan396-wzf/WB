# 响度分析

分析音频峰值/RMS/积分响度（近似 EBU R128 分块门控），检测削波并给出归一化到目标 LUFS 的增益建议，离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/LoudnessForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
