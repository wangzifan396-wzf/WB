# ResistorForge

电阻色环工具：4/5/6 色环互转阻值，支持倍率、容差与六环温度系数，反向可由阻值与容差换算色环，电子入门好帮手。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ResistorForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
