# 色调反转

对高于阈值的通道取反，产生部分负像/日晒效果，阈值可调，所有像素均低于阈值即不变，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/SolarizeForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
