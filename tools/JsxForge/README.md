# JsxForge

把 SVG 代码转成可直接使用的 React/JSX 组件：属性自动转驼峰、style 转对象、空元素自闭合，支持 TypeScript 签名与 props 透传，省去手工改写。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/JsxForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node _test.js   # 内核纯函数断言
node smoke.js   # jsdom 冒烟测试
```
