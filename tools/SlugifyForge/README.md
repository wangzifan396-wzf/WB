# SlugifyForge

生成 URL slug：小写化、去除重音、把非字母数字替换为连字符并折叠多余分隔，适合文章别名与文件名。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/SlugifyForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
