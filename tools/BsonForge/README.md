# BsonForge

BSON 编解码：二进制 JSON 子集（null / 布尔 / 整数 / 双精度 / 字符串 / 数组 / 内嵌文档）的编码与解析。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/BsonForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node _test.js   # 内核纯函数断言
node smoke.js   # jsdom 冒烟测试
```
