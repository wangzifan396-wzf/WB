# UuencodeForge

uuencode 编码 / 解码：把二进制数据转成可打印 ASCII 文本的经典 Unix 方案，曾广泛用于 Usenet 与邮件附件。支持编码与解码，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
