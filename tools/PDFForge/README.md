# PDFForge

本地优先的 **PDF 工具箱** —— 合并、拆分、旋转、重排、优化重存。纯浏览器运行，文件**永不上传**，零后端。

> nano-tools 矩阵的一员（本地优先、单文件、零依赖）。同类工具箱在 GitHub 上不乏高星项目，但 PDFForge 坚持「文件不出浏览器 + 单文件可携」的隐私优先基因。

## ✨ 功能

- **合并** — 按加入顺序把多个 PDF 合成一个
- **拆分** — 按页码规格（`1,3,5-8`）提取页面为新 PDF
- **旋转** — 顺时针 90° / 180° / 逆时针 90°，可累加
- **重排** — 按自定义顺序（`3,1,2,4`）重组页面
- **优化重存** — 无损重新打包（对象流压缩），多数情况可减小体积

## 🔒 隐私

所有处理在浏览器内通过 [PDFLib](https://pdf-lib.js.org/) 完成，文件不会离开你的设备。

## 🚀 使用

直接打开 `index.html`，拖入 PDF 即可。无需安装、无需联网、无需服务端。

## 🧪 测试

```bash
node _test.js      # 纯函数断言
node smoke.js      # jsdom 结构冒烟（需 jsdom）
```

纯函数（页码解析、角度归一、字节格式化、校验）通过 `if(module.exports)` 守卫导出，便于无头测试。
