# 模型卡片生成

按模型名/类型/用途/指标/局限生成标准化模型卡片（含指标表与伦理安全），离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

直接用浏览器打开 `index.html` 即可。
