# WhacForge

打地鼠（Whac-a-Mole）：一只地鼠在 3×3 的格子间随机冒头，戳中得 1 分、戳空扣 1 分，地鼠每次被戳都会换位置。手速与反应力训练，纯前端离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/WhacForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
