# WordScrambleForge

单词乱序（Word Scramble）：从内置英文词库取词并随机打乱字母顺序，你来猜原词，即时反馈对错，做词汇游戏、背单词与无聊消遣随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用
