# NmeaForge

离线 NMEA 0183 语句解析器，逐字段解释 GGA/RMC/GSA/GSV/VTG 等，校验 XOR 校验和并换算经纬度

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/NmeaForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
