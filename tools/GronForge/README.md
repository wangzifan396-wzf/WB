# GronForge

JSON 展平：把嵌套 JSON 转成 json.a.b[0].c = value; 形式的赋值语句，方便用 grep 检索与比对，复制即用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/GronForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言

```
