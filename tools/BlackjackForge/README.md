# BlackjackForge

二十一点（Blackjack）：你与庄家各发两张牌，可不断“要牌”逼近 21 点，超过即爆；庄家在 17 点以下必须补牌。A 可记 1 或 11。提供发牌 / 要牌 / 停牌，纯前端离线赌场经典。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
