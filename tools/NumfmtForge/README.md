# NumfmtForge

人类可读数字互转：1536 ↔ 1.5K，2,000,000 ↔ 2M。支持 K/M/G/T/P/E，方便阅读大数与还原精确值。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/NumfmtForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
