# 像素排序

对亮度高于阈值的连续段按亮度排序，生成拖尾故障艺术；阈值高即不改变，阈值/方向/最大段可调，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/PixelSortForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
