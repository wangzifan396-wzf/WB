# 漫画

白底黑描边 + 亮度加权半调网点，模拟漫画/网点印刷效果，网点大小与描边阈值可调，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ComicForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
