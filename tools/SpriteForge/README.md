# 精灵图切片

将图片按行列数切片为精灵图，计算每格几何并叠加网格，适用于游戏贴图与雪碧图整理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/SpriteForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言

```
