# TowerOfHanoiForge

汉诺塔（Tower of Hanoi）：三根柱子上叠着从大到小的圆盘，目标是把整座塔从 A 柱移到 C 柱，且任何时候大盘不能压在小盘上。提供手动挑战与自动演示，递归算法的经典可视化，纯前端离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/TowerOfHanoiForge/

直接用浏览器打开 `index.html` 即可。
