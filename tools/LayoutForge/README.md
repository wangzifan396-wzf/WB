# 布局生成

布局生成：5 种常见版式（居中/侧边栏/圣杯/网格/堆叠）CSS 生成 + 实时预览，间距可调，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
