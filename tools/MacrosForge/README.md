# 宏量营养

按每日热量目标拆分蛋白/碳水/脂肪克数（4/4/9 kcal/g），并按体重给出蛋白区间。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
