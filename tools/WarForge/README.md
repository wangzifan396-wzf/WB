# WarForge

战争（War）纸牌游戏：双方各发 26 张，每轮亮顶牌比大小，大者收两张；平局则“开战”追加筹码。内置确定性发牌与对战逻辑，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/WarForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

