# RegionalForge

地区指示符（Regional Indicator）生成器：把 A–Z 转成对应的地区指示符号，两个字母连写即组成国旗 emoji（FR → 🇫🇷、JP → 🇯🇵）。纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
