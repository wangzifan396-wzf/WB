# LatexForge

LaTeX 公式渲染（子集）：将常用 LaTeX 数学标记（\frac 分式、^ 上标、_ 下标、\sqrt 根号、希腊字母、\sum/\int 等）离线转换为 HTML 展示，无需联网或重型引擎。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/LatexForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
