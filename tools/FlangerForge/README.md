# 镶边器

短延迟线 + LFO 调制延迟时间，产生喷气机般梳状扫频，可调速率/延迟/干湿/反馈。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/FlangerForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言
node smoke.js   # jsdom 冒烟测试
```
