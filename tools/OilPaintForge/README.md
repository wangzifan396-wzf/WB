# 油画

邻域量化亮度桶取众数桶均值，模拟油画笔触与色块，半径/层级可调，半径 0 即恒等，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/OilPaintForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
