# 正则提取

正则提取：自定义正则或内置预设（邮箱/URL/IPv4/日期/手机号/数字）抽取匹配项，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
