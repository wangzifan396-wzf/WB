# CsvJsonForge

CSV 与 JSON 互转：首行作表头，把 CSV 解析为对象数组，或把 JSON 数组导出为 CSV，正确处理引号与逗号。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CsvJsonForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
