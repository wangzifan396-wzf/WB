# CarbonForge

代码转图片：把代码片段渲染成带 macOS 窗口装饰的漂亮图片（对标 carbon.now.sh / ray.so），内置轻量语法高亮，支持 JavaScript / Python / Bash / JSON / HTML，可切换明暗主题与背景色、调整字号，一键导出 SVG 或 PNG，零依赖、离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
