# DotsForge

点格游戏（Dots and Boxes）：网格上轮流连接相邻圆点，谁围出一个方框就得分并再走一步，终局圈地多者胜。你执 A、机器执 B，纯前端离线经典双人策略。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/DotsForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
