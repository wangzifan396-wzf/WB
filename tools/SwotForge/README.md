# SWOT 分析

SWOT 分析：生成优势/劣势/机会/威胁四象限模板，可预填各项，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
