# KaomojiForge

颜文字（Kaomoji）库：按开心 / 伤心 / 喜欢 / 生气 / 惊讶 / 酷 / 耸肩 / 打招呼分类展示日文表情，支持按字符搜索，点击即复制到剪贴板，聊天与回复随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/KaomojiForge/

直接用浏览器打开 `index.html` 即可。
