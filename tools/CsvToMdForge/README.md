# CsvToMdForge

把 CSV（逗号分隔，支持引号与转义）转换为 Markdown 表格，自动以首行为表头，便于在文档与笔记中粘贴，离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CsvToMdForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
