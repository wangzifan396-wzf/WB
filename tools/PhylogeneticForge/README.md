# 系统发育

系统发育树（UPGMA 层次聚类）：由距离矩阵逐步合并最近类群，估计进化树与分歧高度，离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
