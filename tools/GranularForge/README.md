# 粒子

汉宁窗粒子重组实现时间拉伸（改变时长保留音高），可调粒子大小/拉伸比/重叠，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/GranularForge/

直接用浏览器打开 `index.html` 即可。
