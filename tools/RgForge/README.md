# RgForge

在粘贴的文本中按正则检索，列出命中行号与内容，支持忽略大小写/多行/全局，纯前端、不依赖任何二进制。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

## 本地运行

直接用浏览器打开 `index.html` 即可。
