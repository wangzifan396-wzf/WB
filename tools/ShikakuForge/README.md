# ShikakuForge

四角（Shikaku）谜题：把 N×N 网格划分成若干矩形，使每个带数字的格子恰好位于一个面积为该数字的矩形中。内置题目生成与答案显示，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ShikakuForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
