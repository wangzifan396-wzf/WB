# 域名校验

域名校验：本地正则检查标签/连字符/TLD 合法性，返回 TLD 与标签数，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
