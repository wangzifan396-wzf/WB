# ZalgoForge

恶魔文（Zalgo）生成器：在文字上叠加随机的 Unicode 组合变音符号，营造扭曲、故障般的视觉效果，强度可在上标 / 中缀 / 下标三档调节，做标题、梗图或恶搞文案时随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
