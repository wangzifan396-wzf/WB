# 端口解析

解析端口范围表达式（如 80,443,8000-8100），展开去重并标出知名端口；纯解析/速查，不发起真实扫描。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/PortScanForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
