# 续航估算

续航估算：按电池容量、工作电流与效率估算可用时长（小时/天），并给出 Wh 能量，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
