# WageForge

在时薪、周工时、年工作周之间换算出年薪、月薪与周薪，快速比较不同报价的实际收入。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/WageForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
