# EqnForge

方程求解器：求解一元一次方程 ax+b=0 与一元二次方程 ax²+bx+c=0，给出判别式 Δ、实根（两个/重根）或共轭复根，并展示求解步骤，适合代数学习与作业核对。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
