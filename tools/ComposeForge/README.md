# ComposeForge

docker run 命令与 docker-compose.yml 双向互转：解析 -p/-v/-e/--label/--cap-add/--restart 等常见参数生成服务定义，也能把 compose 服务还原成一行 docker run 命令。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ComposeForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node _test.js   # 内核纯函数断言
node smoke.js   # jsdom 冒烟测试
```
