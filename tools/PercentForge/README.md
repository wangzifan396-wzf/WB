# PercentForge

百分比计算：求 X 的 P%、A 占 B 的百分比、变化率与差异百分比，结果保留两位小数，离线速算。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/PercentForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
