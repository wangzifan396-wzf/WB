# 百分比变化

百分比变化：计算涨跌变化量与变化率（增长/下降/持平），并支持部分占整体比例，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
