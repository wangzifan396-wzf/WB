# Cron解析

Cron 表达式解析（标准 5 段：分 时 日 月 周）：字段通配/列表/范围/步长匹配与可读描述，离线精确。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
