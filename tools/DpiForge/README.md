# DpiForge

PPI / DPI 计算工具：由屏幕对角线英寸与分辨率算出像素密度（PPI），并换算每英寸/毫米对应像素，判断屏幕与图片清晰度。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
