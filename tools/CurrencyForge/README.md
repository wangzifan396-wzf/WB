# CurrencyForge

内置可编辑汇率表（离线），在多种货币间换算并给出交叉汇率；汇率请按实时行情修改。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CurrencyForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
