# 圆角生成

圆角生成：四角半径独立可调，实时预览并输出 CSS border-radius 代码，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/RadiusForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
