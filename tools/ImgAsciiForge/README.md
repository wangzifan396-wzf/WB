# ImgAsciiForge

把图片转换成 ASCII 字符画：内置标准/精细/方块/二值/点阵五套字符梯度，可调输出宽度、伽马与反色，逐格取样亮度映射字符，结果可直接复制。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ImgAsciiForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
