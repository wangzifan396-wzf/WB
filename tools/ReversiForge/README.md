# ReversiForge

黑白棋（Reversi / Othello）：在 8×8 棋盘落子，必须夹住对方至少一枚棋子才能翻转它们。终局占地多者胜，你执黑、机器执白，纯前端离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
