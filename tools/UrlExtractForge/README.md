# URL 提取

URL 提取：从文本抽取链接，自动去除尾部标点，可去重、可去掉查询串，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/UrlExtractForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
