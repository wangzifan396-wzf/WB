# LnavForge

日志分析与查询：自动识别 ERROR/WARN/INFO 等级与时间戳，支持类 SQL 过滤（WHERE level / time / msg、ORDER BY、LIMIT），本地解析不上传。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

## 本地运行

直接用浏览器打开 `index.html` 即可。
