# GachaForge

抽卡（Gacha）模拟：按 N 70% / R 22% / SR 7% / SSR 1% 的概率随机出货，十连保底至少一只 R，做手游抽卡心理建设与无聊消遣随手可用，零依赖离线可玩。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
