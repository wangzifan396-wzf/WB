# YqForge

YAML 与 JSON 互转：粘贴 YAML 解析为结构化 JSON，或把 JSON 美化导出为 YAML。支持嵌套映射、序列、标量与行内结构，离线转换。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/YqForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
