# 放射性衰变

基于指数衰变 N=N0·e^(−λt)，按半衰期求剩余比例、经历半衰期数与反推年龄。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
