# BaconForge

培根密码（Baconian cipher）：把每个字母编码成 5 位 a/b（A=aaaaa …），是最早的二进制编码思想之一，也常被用于字体隐写。支持编码与解码，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
