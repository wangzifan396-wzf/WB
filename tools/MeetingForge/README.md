# 会议纪要

会议纪要：按会议名/时间/参会人/议题生成含结论与行动项的结构化纪要模板，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
