#HashKit
源码

编码 · 哈希 · JWT 一站式

Base64 / URL / HTML 编解码、SHA-256、JWT 解码、UUID 与随机密码 —— 全部本地运算，数据不出浏览器。

SHA-256 为纯 JS 实现（无需联网 / 无需 crypto.subtle）。同样输入永远得到相同摘要。
仅本地解码 Header 与 Payload，不校验签名（签名校验需要密钥）。
