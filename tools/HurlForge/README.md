# HurlForge

用接近 hurl 的文本语法编排 HTTP 请求链：定义方法/URL/请求头/体，断言状态码与响应内容，捕获变量，一键顺序执行。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/HurlForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node _test.js   # 内核纯函数断言

```
