# CaddyForge

Caddyfile 生成器：填域名、反向代理上游、TLS 邮箱、静态根目录等，自动产出带自动 HTTPS 的 Caddy 配置，复制即用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CaddyForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言

```
