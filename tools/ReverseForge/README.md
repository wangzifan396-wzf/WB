# 文本反转

文本反转：将字符顺序倒序排列，支持整段反转或按行反转（不改变行序），离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
