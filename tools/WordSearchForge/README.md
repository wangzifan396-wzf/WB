# WordSearchForge

单词搜索（Word Search）生成器：把一组单词以横、竖、斜、正反向藏进 N×N 字母矩阵，剩余格子用随机字母填充。适合做游戏、课堂活动。纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
