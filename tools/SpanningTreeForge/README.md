# 最小生成树

最小生成树 Kruskal 算法：按权重贪心选边并查集判环，输出 MST 边集与总权重，离线精确。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
