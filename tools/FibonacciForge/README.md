# 斐波那契

斐波那契数列：快倍法求第 n 项（BigInt，支持大数），并可生成前 n 项序列。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/FibonacciForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
