# GlitchForge

故障字（Glitch Text）生成：把部分字母随机替换成全角 / 数学等宽体并叠加删线组合符号，营造“数据损坏、赛博故障”的视觉美学，做标题、专辑封面与梗图随手可用，与恶魔文（变音符号）截然不同的效果。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
