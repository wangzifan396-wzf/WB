# 全角半角

全角半角互转：ASCII 与全角区（FF01–FF5E）互转，空格与 U+3000 对应，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/FullwidthForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
