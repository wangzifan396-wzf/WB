# ReadmeForge

README 与 shields 徽章生成器：填写项目名、描述、许可证与作者，离线生成规范 Markdown 自述与 shields.io 状态徽章（badge URL 构造，不依赖网络）。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ReadmeForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
