# HyperfineForge

基准测试：在浏览器本地多次运行一段 JS 代码，统计最快 / 均值 / 最慢 / 中位数 / 标准差，量化性能差异。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/HyperfineForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node _test.js   # 内核纯函数断言
node smoke.js   # jsdom 冒烟测试
```
