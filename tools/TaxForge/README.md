# 累进所得税

按累进税档估算税额、边际税率与实际税率（内置美国联邦单身 2023 示例税档，可替换）。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/TaxForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
