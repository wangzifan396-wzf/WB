# 卡方检验

卡方独立性检验：由列联表计算 χ² 统计量、自由度与 p 值（基于正则不完全 Gamma 函数），离线精确。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ChiSquareForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
