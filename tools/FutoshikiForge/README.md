# FutoshikiForge

不等式（Futoshiki）谜题：在 N×N 网格里填 1..N，每行每列不重复，且满足相邻格之间的 < / > 约束。内置题目生成与求解，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
