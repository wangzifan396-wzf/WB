# JB正态性

Jarque-Bera 正态性检验：基于样本偏度与峰度计算 JB 统计量与 p 值（χ²(2) 生存函数），离线精确。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/JarqueBeraForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node _test.js   # 内核纯函数断言
node smoke.js   # jsdom 冒烟测试
```
