# KakuroForge

数和（Kakuro，又称 Cross-Sums）谜题：在白色格子里填 1–9，每个横段 / 竖段数字不重复，边缘数字是该段之和。内置题目生成与答案显示，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/KakuroForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
