# FdForge

按文件名模式快速筛选文件清单：支持正则 / 包含 / 精确匹配，输出命中路径与数量，适合从一长串路径里挑文件。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
