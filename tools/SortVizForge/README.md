# SortVizForge

排序算法可视化：任选冒泡 / 插入 / 选择 / 快速 / 归并，把随机数组逐步排好序，实时显示比较与交换次数，直观对比各算法差异，离线零依赖教学利器。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用
