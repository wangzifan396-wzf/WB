# 多普勒效应计算器

声波与光波多普勒效应：由声源/观察者速度求观测频率，或由退行速度求天体红移与波长偏移，全程本地计算。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
