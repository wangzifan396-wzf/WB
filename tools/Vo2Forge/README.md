# VO2max 估算

静息心率法（Uth 公式）与 1.5 英里跑（Cooper）法估算最大摄氧量 VO2max，量化有氧能力。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/Vo2Forge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言

```
