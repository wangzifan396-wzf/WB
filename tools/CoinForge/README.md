# CoinForge

抛硬币工具：一次抛掷多枚，可设置正面概率（模拟加权硬币），显示正面/反面次数与正反面序列，结果可复制。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CoinForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
