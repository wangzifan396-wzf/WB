# DaselForge

数据选择器：用 .a.b[0].c 这样的路径在 JSON 中取值，支持对象键与数组下标，结果格式化输出可一键复制。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/DaselForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
