# RailFenceForge

栅栏密码：按锯齿（zig-zag）路径把字符逐行重排的经典换位密码，不含替换、可被频率分析破译。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/RailFenceForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
