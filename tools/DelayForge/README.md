# 延迟与混响

声速换算距离与延迟、BPM 与每拍毫秒、拍数延迟，以及 Sabine 公式估算房间 RT60 混响时间。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
