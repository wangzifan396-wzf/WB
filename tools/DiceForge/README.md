# DiceForge

骰子投掷工具：支持 NdM 记号（如 3d6、2d20+3）、优势/劣势（D&D 5e 取高/取低），实时显示每颗点数、合计与丢弃值，结果可复制。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/DiceForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
