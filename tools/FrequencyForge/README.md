# 频数表

频数表与直方图分箱：统计每个取值的出现次数与占比，或按箱聚合数据分布。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
