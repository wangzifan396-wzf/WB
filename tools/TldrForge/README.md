# TldrForge

命令速查：内联一份常用 CLI 命令示例库，覆盖 git、npm、docker、kubectl、curl、ssh、tar、grep、awk 等 40+ 工具，输入关键词即检索命令与典型用法，支持分类筛选与一键复制，零依赖、离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
