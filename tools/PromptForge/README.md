# PromptForge · 本地优先 AI Prompt 工作台

> 单文件、零依赖、本地优先的 Prompt 工程工具：变量模板、实时预览、BYOK 直连大模型、成本估算、本地历史。密钥永不离机。

## ✨ 功能

- **变量模板**：用 `{{变量名}}` 占位，改模板即自动提取变量并生成填写面板
- **实时预览**：填入变量后即时看到替换结果，未填的保留 `{{占位}}`
- **BYOK 直连运行**：支持 OpenAI / Anthropic / OpenRouter，粘贴自己的 Key 直连官方接口
- **Token & 成本估算**：按字符粗略估算 token，结合模型单价给出单次成本参考
- **本地历史**：每次运行记录 provider / 模型 / 时间，一键回填
- **密钥安全**：Key 仅存浏览器 `localStorage`，且只发往你选择的官方 API，绝不上传任何第三方

## 🔒 隐私承诺

- 零依赖、零外部请求（除你主动「运行」时直连所选官方 API）
- API Key 不离开你的浏览器，不写入任何远端
- 所有数据（模板、变量、历史）均存于本地

## 🚀 使用

打开 `index.html` 即可，无需安装、无需构建。

## 🧪 测试

```bash
node _test.js     # 纯函数断言
node smoke.js     # DOM 冒烟（需 jsdom）
```

纯函数（模板提取、变量替换、token/成本估算、密钥打码）隔离可测。
