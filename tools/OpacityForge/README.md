# 颜色透明度

颜色透明度：hex 加 alpha 输出 rgba 与 8 位 hex，带色块预览，支持 3/6 位 hex，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
