# 温标换算与热量

摄氏/华氏/开尔文互转，并用 Q=m·c·ΔT 与相变潜热 Q=m·L 估算热量，内置常见比热与潜热表。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
