C Chartify v1.0

数据→图表生成器

粘贴 CSV 或 JSON，一键生成柱状 / 折线 / 饼图（SVG），可导出 PNG。纯本地渲染，零上传、零依赖。

示例：
CSV：首行表头，逗号分隔
JSON：[{ "月份":"1月", "访问量":1200 }] 或 [10,20,30]
