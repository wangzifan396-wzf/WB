# SnipForge

> Local-first code snippet manager — folders, tags, full-text search, one-click copy, JSON import/export, works offline.

本地优先的代码片段管理器：分类、标签、全文搜索，一键复制，JSON 导入导出，离线可用。

A flagship member of the **nano-tools** matrix (GitHub org `wangzifan396-wzf`):
offline-first, single-file, zero-dependency developer tools.

---

## Features / 功能

- **Snippets** — store reusable code fragments (SQL, JS, CSS, bash, regex, config…) with folder, tags, and favorite. / 片段：文件夹、标签、收藏。
- **Folders & tags** — organize by folder and free-form tag chips; filter sidebar by folder, language, and favorite. / 文件夹与标签：侧栏按文件夹、语言、收藏筛选。
- **Full-text search** — matches title / code / tags, case-insensitive, with safe in-list highlight. / 全文搜索：匹配标题、代码、标签，大小写不敏感，列表内安全高亮。
- **One-click copy** — `navigator.clipboard.writeText` with `execCommand` fallback. / 一键复制：优先 Clipboard API，降级到 execCommand。
- **Import / Export** — single `.json` file via Blob + object URL; malformed input is rejected with a toast (never `eval`). / 导入导出：Blob 下载 JSON，非法文件以提示拒绝，绝不使用 eval。
- **Persistence** — autosave to `localStorage` (key `snipforge.v1`); sample snippets preloaded on first run. / 持久化：自动存入 localStorage，首次运行预置示例。
- **Bilingual** — zh / en toggle, persisted. / 中英双语切换并持久化。
- **Keyboard** — `/` focuses search, `n` new snippet. / 快捷键：`/` 搜索，`n` 新建。
- **Security** — all user data rendered via `textContent` (no `innerHTML` for user input), no `eval`. / 安全：用户数据一律走 textContent，不用 innerHTML，不用 eval。

## Design system / 设计系统

Linear-dark, offline-first. Canvas `#0A0A0B`, card `#141417`, surface `#1A1B1E`,
text `#FFFFFF`/`#A1A1AA`/`#71717A`, accent `#5E6AD2`. System font stack, zero external
requests, `prefers-reduced-motion` respected.

## Architecture / 架构

| File | Purpose |
|------|---------|
| `template.html` | Source of the real app (HTML + CSS + JS in one file). |
| `build.py` | Identity copy `template.html` → `index.html`. |
| `index.html` | Shippable single file (generated by `build.py`). |
| `_test.js` | Node pure-function unit tests (no deps). |
| `smoke.js` | jsdom smoke test (boots with 0 fatal errors). |
| `sw.js` | Service worker (offline-first, cache-first). |
| `manifest.webmanifest` | PWA manifest. |
| `og.svg` | 1280×640 social preview. |

The JS keeps **pure logic** (exported via `module.exports` for Node tests) separate from
**UI code** (guarded by `if (typeof window !== 'undefined')`). No `if (typeof window ===
'undefined') return;` at top level.

## Build & test / 构建与测试

```bash
python3 build.py      # template.html -> index.html (identity copy)
node _test.js         # pure-function tests
node smoke.js         # jsdom smoke test
```

Requires Node 20+ and jsdom (already present in the workspace) for `smoke.js`.
