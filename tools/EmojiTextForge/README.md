# EmojiTextForge

emoji 字母：把每个英文字母按“发音/形象”映射成一个 emoji（a→🍎、c→🐱、s→☀️），把单词拼成一组 emoji 画，做趣味签名、儿童识字与社媒装饰随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用
