# LolcatForge

彩虹文字：把每行文本按字符做 HSV 色相渐变，输出带内联样式的彩色文字，复制即用于文档或终端回放。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/LolcatForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

node _test.js   # 内核纯函数断言
