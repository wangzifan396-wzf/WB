# 图像裁剪

校验并夹取裁剪矩形（防止越界），给出有效区域与面积、宽高比。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
