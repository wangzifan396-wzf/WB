# 露点湿度

由温度与相对湿度求露点（Magnus 公式）与绝对湿度（g/m³），辅助体感与结露判断。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

## 本地运行

直接用浏览器打开 `index.html` 即可。
