# 波长/光子能量

波长/频率/光子能量：λ = c/f、E = h·f，支持可见光与射频波段。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
