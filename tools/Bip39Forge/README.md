# BIP39助记词

BIP39 助记词生成与校验（含 SHA-256 校验和）及 PBKDF2-HMAC-SHA512 种子派生，离线客户端运行，永不离开本机。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
