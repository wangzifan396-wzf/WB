# 术语表生成

批量解析「术语: 定义」生成排序术语表（表格/列表），支持字母序与长度排序，离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/GlossaryForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
