# 水彩

边缘柔化 + 降饱和 + 颗粒/纸纹，模拟水彩晕染的清透质感，柔化/饱和/纸纹可调，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
