# TtsForge

文本转语音工具：调用浏览器内置的 SpeechSynthesis 离线朗读任意文本，可选语言、音色、语速与音调，数据不出本机。适合校对文案、辅助阅读与语言学习。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
