# RainbowForge

彩虹字生成：把输入文字按字符位置映射成一条 HSL 彩虹渐变，可调字号，适合做标题、配图与社媒装饰，纯前端、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/RainbowForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
