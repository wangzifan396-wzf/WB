# CrazyEightsForge

疯狂八号（Crazy Eights）纸牌游戏：出与顶牌同点数或同花色的牌，8 可当任意牌。内置发牌与合法出牌判定，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CrazyEightsForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node _test.js   # 内核纯函数断言

```
