# FrakturForge

哥特体 / 花体（Fraktur）生成器：把字母转成 Unicode 哥特字母（𝔉𝔯𝔞𝔨𝔱𝔲𝔯），常用于金属乐、纹身、装饰排版。纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
