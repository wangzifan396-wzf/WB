# YamlForge

离线 YAML ⇄ JSON 转换器。纯前端、零依赖、数据永不离机。

## 功能
- **YAML → JSON**：解析块级映射 / 序列、多级嵌套、类型推断（null / bool / int / float / string）、单双引号标量与转义、行内注释。
- **JSON → YAML**：序列化为 2 空格缩进的块级 YAML，字符串按需加引号以保留类型。
- **双向校验**：非法输入在界面给出友好报错。

## 支持与限制
- 支持：块级映射、块级序列、嵌套、类型推断、带引号标量、行内注释。
- 不支持：Flow 风格（内联 `{a:1}` / `[1,2]`）、锚点 & 别名、多文档、块标量（`|` 与 `>`）、时间戳自动解析。遇到此类输入会按字符串保守处理。

## 用法
直接用浏览器打开 `index.html` 即可，无需安装、无需联网。

## 测试
```bash
node _test.js      # 纯函数断言（含往返一致性）
node smoke.js      # jsdom UI 冒烟（需 npm i jsdom）
```
