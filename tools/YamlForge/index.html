YAML ⇄ JSON 双向转换。纯前端、零依赖、数据永不离机。支持块级映射 / 序列、嵌套、类型推断与带引号标量。

YAML → JSON

JSON → YAML

支持与限制

支持：块级映射（key: value）、块级序列（- item）、多级嵌套、类型推断（null / bool / int / float / string）、单双引号标量与转义、行内注释。
不支持：Flow 风格（{a: 1} 或 [1,2] 内联）、锚点 & 别名、多文档、块标量（| 与 >）、时间戳自动解析。遇到此类输入会按字符串保守处理。
