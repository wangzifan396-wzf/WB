# 竞品对比

按自家产品/竞品/维度与对比矩阵生成竞品对比分析（含骨架），离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
