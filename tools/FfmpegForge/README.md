# FfmpegForge

FFmpeg 命令助手：十套常用配方一键生成压缩、转码、切片、转 GIF、抽帧等命令；解释模式逐个参数给出中文含义，并提示 -c:v copy 与滤镜冲突等常见坑。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
