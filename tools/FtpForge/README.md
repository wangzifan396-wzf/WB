# FTP 解析

解析 ftp/ftps/sftp URL，提取 scheme、主机、端口、认证、路径与查询，纯离线解析。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/FtpForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
