# 强酸强碱滴定

强酸–强碱滴定：自动算当量体积与任意加碱量下的 pH（含当量点=7），并可生成滴定曲线关键点。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
