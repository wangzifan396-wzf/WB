# 黑色电影

去色 + 对比强化 + 胶片颗粒 + 暗角，模拟黑色电影/悬疑质感，对比/颗粒/暗角可调，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用
