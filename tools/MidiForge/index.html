关于

标准 MIDI 文件由一个 MThd 头块和若干 MTrk 轨道块组成。头块给出 format（0 单轨 / 1 多轨同步 / 2 多轨独立）、轨道数和 division（每四分音符的 tick 数，或 SMPTE 帧率）。

轨道内每个事件前都有一个变长量（VLQ）delta time：每字节用低 7 位存数据，最高位为 1 表示后面还有字节。事件可以省略状态字节沿用上一个，这叫 running status，解析时必须记住它。

tick 转秒需要速度表：seconds = ticks / division × (microsecondsPerQuarter / 1e6)，遇到 Set Tempo 元事件就换算率。本工具把这些都在本地算完，文件不出浏览器。
