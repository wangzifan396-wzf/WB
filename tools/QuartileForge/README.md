# 四分位数

四分位数 Q1/Q2/Q3 与四分位距 IQR（线性插值法，同 NumPy 默认），附最小/最大。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
