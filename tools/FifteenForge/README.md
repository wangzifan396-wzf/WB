# FifteenForge

15 数码谜题（Sliding Puzzle）：4×4 网格中滑动方块，把数字 1-15 按顺序排列、空格留在右下角。提供打乱与复原，做逻辑训练与无聊消遣随手可用，纯前端离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
