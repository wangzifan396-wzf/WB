# DrawForge · 离线白板

纯前端、零依赖的离线白板：手绘风画笔、矩形、椭圆、箭头、文本，自由平移缩放，一键导出 PNG / SVG，自动保存在浏览器本地。数据永不离机。

[▶ 在线体验](https://wangzifan396-wzf.github.io/WB/tools/DrawForge/) · [⭐ GitHub](https://github.com/wangzifan396-wzf/WB/tree/main/tools/DrawForge)

## ✨ 功能

- **手绘风渲染**：基于确定性种子的 rough 笔触，线条自然而不呆板。
- **六种工具**：选择 / 移动、画笔、矩形、椭圆、箭头、文本、橡皮。
- **自由画布**：空格 + 拖拽平移，滚轮缩放，双击 / `F` 适应屏幕。
- **选中变换**：点击选中，拖拽移动，八向控制点缩放（矩形 / 椭圆 / 箭头 / 画笔 / 文本通用）。
- **导出**：一键导出 PNG 与 SVG（矢量，背景透明可选），便于插入文档或二次编辑。
- **本地保存**：所有内容自动存入 `localStorage`，刷新不丢；清空可一键还原。
- **快捷键**：`V/P/R/O/A/T/E` 切换工具，`Del` 删除，`Ctrl+Z / Ctrl+Shift+Z` 撤销重做。
- **中英双语**：跟随浏览器语言，右下角一键切换。
- **离线优先**：单文件 HTML，无构建、无后端、无外部请求。

## 🧰 技术

- 纯原生 JavaScript + Canvas 2D，零运行时依赖。
- 确定性伪随机（mulberry32）保证手绘抖动在重绘 / 导出间稳定一致。
- PNG 与 SVG 导出共用同一套几何生成，所见即所得。
- 设计遵循 nano-tools 统一的 Linear 冷峻暗色系统（`#5E6AD2` 品牌靛蓝）。
