# BridgesForge

搭桥（Hashiwokakero）谜题：在网格里连接所有小岛，每座岛连出的桥数必须等于岛上的点数，且桥与桥不能交叉。内置题目生成与答案显示，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/BridgesForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
