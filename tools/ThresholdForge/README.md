# 二值化

按亮度阈值生成黑白二值图，可选平滑过渡带与反相，平滑 0 即硬阈值，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ThresholdForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言
node smoke.js   # jsdom 冒烟测试
```
