# 贷款摊销

贷款摊销日程：按月等额本息，计算月供、每期本金/利息与余额，以及总利息。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
