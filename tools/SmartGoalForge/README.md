# SMART 目标

SMART 目标：生成具体/可衡量/可实现/相关/有时限五要素拆解模板与里程碑占位，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
