# StegForge

零宽隐写术 —— 单文件、零依赖、本地优先。把秘密消息藏进任意文本的零宽字符里，肉眼与排版完全不可见，复制即携带。

- 编码：秘密消息 → 自研 UTF-8 字节 → 8 位二进制 → U+200B(0) / U+200C(1)，U+200D 起始、U+2060 终止标记。
- `sgHide(cover, secret)`：注入载荷（防二次隐写），可见文本零变化（`sgStrip` 后与原文全等）。
- `sgReveal(text)`：起止标记定位 + 位流还原 + UTF-8 解码，损坏载荷精确报错。
- `sgDetect(text)`：零宽字符计数 / 完整载荷判定 / 可见长度——也可自查「收到的文本有没有被做手脚」。
- 支持中文与 emoji 秘密消息（自研 UTF-8 编解码，含 4 字节码点）。
