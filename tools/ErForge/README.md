# ErForge

从 SQL DDL 生成 ER 图：解析 CREATE TABLE、列、主键与外键，自动绘制表框与关系连线，本地渲染、可缩放查看。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ErForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
