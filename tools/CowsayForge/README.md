# CowsayForge

Cowsay 生成：把你输入的话包进 ASCII 对话气泡，下面配一只经典小牛，单句或多行都支持，做终端风表情包、命令行梗与趣味回复随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

## 本地运行

直接用浏览器打开 `index.html` 即可。
