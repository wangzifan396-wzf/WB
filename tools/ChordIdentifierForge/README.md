# 和弦识别

输入一组音名（如 C,E,G）识别根音与和弦性质（大/小/属七/大七/挂留/增减等），支持转位。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ChordIdentifierForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
