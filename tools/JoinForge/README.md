# JoinForge

文本合并工具：把多段文本（每行一个块）按所选分隔符拼接成一行或一段，支持去除首尾空白、跳过空行、添加序号前缀，整理列表与批量拼接时随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
