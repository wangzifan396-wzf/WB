# SdForge

查找替换：支持纯文本与正则两种模式，可选全局、忽略大小写，实时显示替换处数与结果，等价于 sd / sed 的常用场景。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/SdForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
