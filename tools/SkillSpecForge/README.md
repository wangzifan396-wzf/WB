# Skill 规格

按名称/描述/触发条件/步骤/安全约束生成标准 SKILL.md（含 YAML frontmatter），离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

直接用浏览器打开 `index.html` 即可。
