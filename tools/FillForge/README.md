# 文本对齐

文本对齐：按字符数批量填充到指定宽度，支持左/右/居中对齐与自定义填充字符，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
