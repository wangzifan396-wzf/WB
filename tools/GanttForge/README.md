# GanttForge

甘特图生成器 —— 单文件、零依赖、本地优先。CSV 风格任务表一键出图，排期评审 / 项目周报 / 里程碑跟踪不用开重型项目软件。

- 行格式：`任务名, 开始日 YYYY-MM-DD, 天数[, 进度%]`，中英文逗号均可，`#` 行注释。
- `gtParse(text)`：逐行校验（日期合法性含 2-30 这类假日期、天数正整数、进度 0-100），精确报错行号。
- `gtStats(tasks)`：总跨度天数 + 按工期加权的整体进度。
- `gtOverlaps(tasks)`：两两检测时间重叠的任务对（资源冲突预警）。
- `gtSvg(text)`：暗色 SVG，日期刻度自适应密度，进度条满 100% 变绿。
