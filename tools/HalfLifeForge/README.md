# HalfLifeForge

衰变剩余量、由现存比例推算地质 / 考古年代，内置常用同位素半衰期。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
