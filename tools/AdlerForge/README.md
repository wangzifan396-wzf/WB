# AdlerForge

Adler-32 校验和：计算文本或字节流的 32 位校验值，常用于 zlib 校验与文件完整性快速比对，离线计算。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/AdlerForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
