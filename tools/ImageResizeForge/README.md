# 图片缩放裁剪

基于 Canvas 的离线图片缩放与裁剪：等比 contain / 填充 cover / 精确拉伸，指定锚点裁剪并导出 PNG。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
