# 移动平均

移动平均：简单移动平均 SMA（窗口均值）与指数移动平均 EMA（平滑系数 α），离线计算。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
