# 采样率与体积

由采样率、时长、声道与位深估算 PCM 数据量与样本数，并列出常用采样率对照。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
