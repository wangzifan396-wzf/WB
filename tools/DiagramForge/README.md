# DiagramForge

**单文件 · 零依赖 · 离线优先的流程图 / 图表编辑器。** 你拥有它、可审计、可改。

在浏览器里双击 `index.html` 即可使用 —— 无需服务器、无需构建、无需联网、不收集任何数据。画完的图只存在你本机（localStorage）。

> 这是 nano-tools 矩阵的一个「重量级单文件应用」：与矩阵里 100 款轻量工具互补，DiagramForge 补足了单文件生态里一直空缺的 **draw.io / Excalidraw 替代** 这一品类。

## 特性

- **图形丰富**：矩形、圆角矩形、椭圆、菱形、平行四边形、圆柱（数据库）、纯文本、便签。
- **连线**：从节点锚点拖出箭头，自动选择最优连接边；支持直角 / 直线两种线型，可加连线标签。
- **编辑**：拖拽移动、八向手柄缩放、双击编辑文字、框选多节点、网格吸附。
- **样式**：填充 / 边框 / 文字色 / 字号 / 线宽 / 圆角均可调；置顶置底、复制。
- **撤销重做**：完整命令历史（Ctrl+Z / Ctrl+Y）。
- **模板**：空白、流程图、UML 类图、网络拓扑、思维导图，一键起步。
- **导出**：SVG（矢量，可继续编辑）、PNG（2x 高清）、JSON（可再导入）；导入 JSON 继续编辑。
- **离线**：PWA，可安装到桌面；断网照常使用。
- **零依赖**：纯原生 SVG + JS，系统字体，无外部请求、无第三方库。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `V` | 选择工具 |
| `C` | 连线工具 |
| 空格 + 拖拽 | 平移画布 |
| 双击节点 | 编辑文字 |
| `Del` / `Backspace` | 删除选中 |
| `Ctrl/⌘ + Z` / `Shift+Z` | 撤销 / 重做 |
| `Ctrl/⌘ + D` | 复制选中 |
| 方向键 | 微移（Shift = 像素级） |
| 滚轮 | 缩放（以光标为中心） |

## 与矩阵的关系

DiagramForge 是 nano-tools 组织下的独立仓库，延续同一套设计语言（Linear 冷峻暗色）与「单文件、零依赖、可审计」的价值观。门户 `WB` 负责导航，本仓库是其中的一张「重量级应用」卡片。
