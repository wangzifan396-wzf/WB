# 数据损坏

分带水平错位 + 向下涂抹拖影，模拟数据损坏/视频 datamosh 故障艺术，分带/错位/涂抹可调，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/DatamoshForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
