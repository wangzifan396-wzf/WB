# PolybiusForge

波利比奥斯方阵（Polybius Square）密码：把每个字母映射到 5×5 方阵里的行列坐标（如 A=11、B=12），是古希腊的古典替代密码，也常用于间谍通信。支持编码与解码，纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
