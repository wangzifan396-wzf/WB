# ConnectForge

四子连线（Connect Four）：6×7 棋盘，点击列把棋子落到该列底部，水平 / 垂直 / 两条对角线任意方向先连成四子者获胜。你执红，机器随机应对，纯前端离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
