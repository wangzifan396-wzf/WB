# PeForge

离线 PE/COFF 可执行文件头解析器，展开 COFF、Optional 头、数据目录与节表，并检查 DEP/ASLR/W^X

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/PeForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
