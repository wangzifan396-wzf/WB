# HoroscopeForge

星座运势：输入生日自动算出你的太阳星座，并随机给一句当日短运提示，纯前端、零依赖、仅供娱乐，做 daily ritual 与无聊消遣随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
