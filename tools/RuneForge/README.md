# RuneForge

卢恩符文（Elder Futhark）转换：把拉丁字母转写成古日耳曼卢恩文字，或反向还原（近似音值），做奇幻设定、纹身灵感与北欧风文案随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/RuneForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
