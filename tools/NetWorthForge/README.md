# NetWorthForge

汇总资产与负债列表，一键算出总资产、总负债与净资产，掌握财务健康度。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/NetWorthForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
