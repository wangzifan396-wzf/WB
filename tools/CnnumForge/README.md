# CnnumForge

中文数字与阿拉伯数字互转：支持 零~九、十百千万亿，可处理“三百零五”“一亿零一万”等，便于中文票据与读数，离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/CnnumForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
