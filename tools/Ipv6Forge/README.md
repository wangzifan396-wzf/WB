# IPv6 地址转换

IPv6 地址在点分十进制与压缩格式间互转，并识别类型（环回/链路本地/唯一本地/多播/全球单播/IPv4 映射）。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/Ipv6Forge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash

```
