# IPv4 进制转换

IPv4 地址在点分十进制、十进制整数、二进制、十六进制间互转，并判定类别（A/B/C/D/E）与作用域（公网/私网/回环）。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
