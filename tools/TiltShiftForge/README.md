# 移轴微缩

上下渐变模糊、保留中心清晰带，模拟移轴微缩模型效果，模糊/清晰带/位置可调，模糊 0 即恒等，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
