# 在线统计

Welford 单遍在线统计：由样本流实时更新均值、样本方差与标准差，数值稳定，离线精确。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
