# 小费计算器

餐厅小费与 AA 拆分：按账单与比例算小费、合计与人均，并支持向上取整到元。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
