# 盒模型

盒模型：按宽高/内边距/边框/外边距计算内容区与总占用尺寸，支持 content-box 与 border-box，带可视化，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

## 本地运行

直接用浏览器打开 `index.html` 即可。
