# ExtractForge

文本抽取工具：用内置正则预设一键从任意文本中抽取邮箱、网址、IPv4 地址、电话号码、数字或十六进制颜色，也支持自定义正则，结果逐行列出并附计数，整理日志与抓取的得力助手。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
