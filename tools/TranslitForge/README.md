# TranslitForge

音译工具：将希腊字母与西里尔字母（俄语等）按通用方案转写为拉丁字母，便于检索与输入，纯映射表实现、离线可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/TranslitForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
