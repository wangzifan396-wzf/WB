# 蛋白质序列翻译

标准遗传密码将 mRNA 序列翻译为单字母蛋白质链（含起始/终止），支持三个阅读框，纯前端处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ProteinForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
