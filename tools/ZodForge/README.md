# ZodForge

把 JSON 示例数据转成 Zod 校验 Schema：自动识别邮箱、URL、UUID 与 ISO 时间等格式，数组元素合并后标记 optional 与 nullable，并附带 z.infer 类型导出。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/ZodForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
