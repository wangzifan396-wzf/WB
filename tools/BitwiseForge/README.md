# BitwiseForge

位运算计算器：对整数做按位与/或/异或/取反、左移右移与循环移位，并以二进制可视化，支持 0x/0b/十进制输入。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/BitwiseForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
