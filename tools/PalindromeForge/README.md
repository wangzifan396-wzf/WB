# PalindromeForge

回文检测：判断一段文字是否为回文（自动忽略空格、标点与大小写，也支持中文），并额外找出文本中的最长回文子串，做文字游戏与算法练习随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用
