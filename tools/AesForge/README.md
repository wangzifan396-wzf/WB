# AesForge

本地 AES 对称加密与解密：支持 GCM/CBC/CTR 与原始十六进制密钥，或用口令经 PBKDF2 派生密钥；全部运算在浏览器内完成，数据不出本机。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/AesForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
