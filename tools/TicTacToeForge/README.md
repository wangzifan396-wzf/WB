# TicTacToeForge

井字棋（Tic-Tac-Toe）：你执 X 先手，机器执 O，采用极小化极大（Minimax）算法做出最优应对——除非你先手走错，否则最多平局，无法被战胜。做算法演示与无聊消遣随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
