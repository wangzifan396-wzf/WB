# 工作日计算

工作日计算：统计区间内工作日数（排除周末），可指定节假日，起止自动排序，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/WorkdayForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

