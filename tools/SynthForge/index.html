关于

减法合成的思路是先做一个谐波丰富的波形，再用滤波器削掉不要的部分。锯齿波含全部谐波，方波只含奇次谐波，三角波同样只有奇次但衰减更快，正弦波则没有谐波。

ADSR 包络控制音量随时间的走向：attack 起音、decay 衰减到 sustain 电平、松键后按 release 归零。滤波器是一极低通 y[n] = y[n-1] + α(x[n] − y[n-1])，其中 α = dt / (RC + dt)。

导出时不用 WebAudio 录音，而是纯 JS 逐采样离线渲染，再手写 RIFF/WAVE 头封装成 16-bit PCM，因此结果完全确定、可重复。
