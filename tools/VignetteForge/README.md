# 暗角

以图像中心为原点、按归一化距离线性压暗四周，营造暗角/聚光效果，强度/半径可调，强度 0 即恒等，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
