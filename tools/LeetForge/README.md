# LeetForge

leet 体（黑客语 / Leetspeak）转换：把字母按经典映射替换成数字与符号（a→4、e→3、t→7…），可做密码灵感、游戏 ID 与梗图文案，支持激进模式保留部分原形。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
