# Sm4Forge

SM4 国密分组密码：符合 GB/T 32907 的 128 位对称加密（ECB 模式 + PKCS#7 填充）。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/Sm4Forge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

