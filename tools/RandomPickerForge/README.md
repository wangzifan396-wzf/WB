# 随机抽签器

从候选列表中随机抽取，支持不重复/可重复两种模式与随机种子复现，适合抽签、抽奖、分组。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/RandomPickerForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
