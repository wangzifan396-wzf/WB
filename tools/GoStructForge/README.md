# GoStructForge

把 JSON 示例数据转换成 Go struct 定义：自动推导字段类型、生成 PascalCase 字段名与 json tag，支持嵌套结构、数组元素合并、omitempty 与 yaml tag。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/GoStructForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言

```
