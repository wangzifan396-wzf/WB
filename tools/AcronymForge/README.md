# AcronymForge

缩略词工具：一边把长句压缩成首字母缩写（ASAP / API），一边把缩写按词库随机展开成有趣的短语，做命名、记忆法与玩笑文案随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
