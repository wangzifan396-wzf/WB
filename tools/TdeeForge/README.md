# TdeeForge

用 Mifflin-St Jeor 与 Harris-Benedict 两种公式算基础代谢 BMR，再按活动量乘出每日总消耗 TDEE 与目标摄入。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/TdeeForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 测试

```bash
node _test.js   # 内核纯函数断言
node smoke.js   # jsdom 冒烟测试
```
