# HangmanForge

猜单词（Hangman）：从内置英文词库随机选词，你逐字母猜测，错 6 次即失败。显示已猜字母、剩余机会与当前进度，做词汇游戏与无聊消遣随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用
