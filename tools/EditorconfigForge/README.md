# EditorconfigForge

.editorconfig 生成器：设定缩进风格/宽度、字符集、换行符与结尾换行等，可选地附加按扩展名的覆盖段，一键产出规范文件。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

直接用浏览器打开 `index.html` 即可。
