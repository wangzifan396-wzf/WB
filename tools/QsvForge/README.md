# QsvForge

像 qsv 一样用 SQL 查询 CSV：SELECT 列、WHERE（= != > < >= <= LIKE CONTAINS，支持 AND）、ORDER BY、LIMIT，全部在浏览器内完成。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/QsvForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。

```bash
node _test.js   # 内核纯函数断言

```
