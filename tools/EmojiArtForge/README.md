# EmojiArtForge

emoji 画（Emoji Art）：一组用 emoji 拼出的小图案——爱心、星星、猫、花、彩虹等，点击即可整段复制到剪贴板，做聊天装饰、贺卡与社媒配图文案随手可用。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

https://wangzifan396-wzf.github.io/WB/tools/EmojiArtForge/

## 本地运行

直接用浏览器打开 `index.html` 即可。
