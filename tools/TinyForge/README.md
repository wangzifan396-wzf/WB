# TinyForge

上标下标（Tiny text）生成器：把字母与数字转换成 Unicode 上标（ᵗⁱⁿʸ）或下标（ₜᵢₙᵧ）形式，常用于化学式、脚注、可爱排版。纯本地、零依赖。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

直接用浏览器打开 `index.html` 即可。
