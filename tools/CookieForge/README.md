# Cookie 解析

解析/校验/构造 RFC 6265 Set-Cookie，并按域名、路径、Secure、过期规则判定是否随请求发送，离线。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
