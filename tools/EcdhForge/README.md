# EcdhForge

本地 ECDH（P-256）密钥协商演示：Alice 与 Bob 各自生成密钥对，用对方公钥派生出一致的共享密钥，可用于进一步派生对称加密密钥。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
