# 血氧评估

根据 SpO2 数值评估低氧程度并提示是否需补氧，离线演示。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

直接用浏览器打开 `index.html` 即可。
