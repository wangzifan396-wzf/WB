# 形变

径向 bulge/pinch 球面形变（凸起/凹陷），强度 0 即恒等映射，可调中心与半径，离线处理。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
