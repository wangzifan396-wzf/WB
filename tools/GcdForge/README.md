# 最大公约数

计算多个整数的最大公约数、最小公倍数、质因数分解并判定互质。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
