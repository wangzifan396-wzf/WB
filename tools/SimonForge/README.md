# SimonForge

Simon（记忆翻色）：电脑依次点亮一组颜色方块，你照着顺序点击重复；每过一轮就多加一步，比拼你的短时记忆极限，纯前端离线可玩。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用

## 在线使用

直接用浏览器打开 `index.html` 即可。
