# CleanForge

文本清洗工具：一键整理从 PDF、网页或日志复制来的脏文本——去除行尾空白、删除空行、把连续空行压缩为一行、可选去重行、Tab 转空格，并统一换行符（LF/CRLF/CR）。

- 单文件 HTML，零依赖，打开即用
- 数据全程留在本机，不上传任何服务器
- 支持 PWA 安装与离线使用
