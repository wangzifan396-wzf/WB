常见问答

你可能想问

真的完全零依赖、可离线使用吗？
是的。每个工具都是自包含的单文件 HTML，内联了全部 CSS 与 JavaScript，不引用任何外部字体、脚本或网络接口。断网、双击文件即可运行。
我的数据会被上传吗？
不会。所有处理（文本解析、图片压缩、token 估算、图谱布局等）都在浏览器本地完成，没有任何网络请求，文件与内容不会离开你的设备。
这些工具是怎么开源的？
全部以 MIT 许可证发布在 GitHub（wangzifan396-wzf 名下），每个工具独立仓库并启用 GitHub Pages 在线 demo。你可以免费使用、修改、再分发。
我想贡献一个新工具，怎么做？
欢迎在任意仓库提交 Issue 或 Pull Request。如果你有想法但还没写代码，也可以先开 Issue 讨论；设计目标是保持「单文件、零依赖、本地优先」。
移动端能用吗？
可以。门户与大部分工具都做了响应式适配，手机浏览器打开同样可用；少数依赖拖拽或精确指针交互的功能在触屏上体验会略有折损。
