# AI 发展趋势 · 2025–2026

一份关于 AI 发展趋势的单文件可视化网站（可交互 HTML）。

## 预览

直接用浏览器打开 `index.html` 即可，**无需额外构建步骤、无需联网**。

## 特性

- **单文件、零依赖**：HTML / CSS / JS 全部内联，不加载外部字体、图片或脚本，秒开。
- **工程冷峻风（Linear 美学）**：近黑底、细线边框、等宽字体标注、青→靛→粉渐变标题。
- **轻量交互，不卡顿**：滚动揭示（`IntersectionObserver`）、数字滚动计数（`requestAnimationFrame`）、对比条动画，全部只使用 `transform` / `opacity`（GPU 合成层）；尊重 `prefers-reduced-motion`。
- **明暗主题**：内置暗色（默认）/ 亮色切换，偏好通过 `localStorage` 持久化。
- **细节交互**：滚动进度条、毛玻璃导航、来源跑马灯、回到顶部。

## 内容结构

- **关键数据**：生成式 AI 市场规模、企业采用率、推理成本降幅、中美投资差距
- **六大核心切片**：Agent 化跃迁 / 推理成本崩塌 / 多模态融合 / 端侧智能爆发 / 垂直行业深耕 / 治理与对齐
- **中美欧三极格局**：美国 / 中国 / 欧盟对比 + 私营 AI 投资对比条
- **2026 五条关键预测**：标注高 / 中 / 低信度

## 数据来源

数据取自下列机构的公开报告（2025–2026），并在页面内逐条标注：

- Stanford HAI — AI Index 2026
- McKinsey — State of AI 2025
- a16z — LLMflation
- Gartner — 生成式 AI 支出预测
- IDC — 硬件支出

> 注：数值为公开报告的四舍五入引用，仅供研究参考，不构成投资建议。

## 技术说明

- 纯原生 HTML / CSS / JS，无框架、无打包器。
- 性能策略：系统字体栈（避免中文字体下载）、动画仅合成层、被动滚动监听 + `requestAnimationFrame` 合批。
- 兼容：现代浏览器（Chrome / Edge / Safari / Firefox 近两个大版本）。
